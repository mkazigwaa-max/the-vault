01

Set up

Get your accounts ready

Help me get ready to use “The Content Coach Stack”. Read the guide at https://mkazigwaa-max.github.io/the-vault/resources/25 first. First check that you can drive a browser (Claude in Chrome, computer use, or this app's own browser tool). If you can't, tell me in one line how to turn that on in the app I'm using, then carry on with links. Use your browser tools to inspect what I already have connected and help me open or create the accounts this guide actually needs. Start with my existing accounts. The tools below include alternatives; do not sign me up for every option. Ask me to choose only where the guide requires a choice. Open only the relevant setup links, grouped by the job they do: - Apify — Web and social data collection: https://mkazigwaa-max.github.io/the-vault/resources/25 - Claude — AI assistant: https://mkazigwaa-max.github.io/the-vault/resources/25 - Firecrawl — Website extraction: https://mkazigwaa-max.github.io/the-vault/resources/25 - Unipile — Messaging and social connections: https://mkazigwaa-max.github.io/the-vault/resources/25 - Composio — Connects Claude to my Instagram for OP1 and Path A: https://dashboard.composio.dev (sign up or sign in there) - Gemini Notebook (the new name for NotebookLM since July 2026) — Audio lessons and notebooks: https://mkazigwaa-max.github.io/the-vault/resources/25 Connecting the tools to Claude (updated October 2026; the PDF's wiring pages show older commands): - Composio and Apify both have official Claude Code plugins. The commands that start with / are ones I type into Claude Code myself (you can't run them), so tell me exactly what to type, one at a time, and wait for me: /plugin marketplace add ComposioHQ/composio-plugin-cc then /plugin install composio@composio, and /plugin marketplace add apify/apify-claude-code-plugin then /plugin install apify@apify. Then install the Composio CLI if it's missing (curl -fsSL https://composio.dev/install | bash; not pip install composio, which has no CLI) and run composio login (you can run both; I sign in when the browser opens), and I type /composio-connect instagram. For Apify, I type /mcp, open plugin:apify:apify and sign in. If I'd rather use a Composio API key, the header goes in quotes with a space: claude mcp add --scope user --transport http composio https://connect.composio.dev/mcp --header "x-consumer-api-key: YOUR_KEY". In Claude Desktop, add https://connect.composio.dev/mcp and https://mcp.apify.com as custom connectors. - Gemini Notebook has no official API. Use the maintained gemini-notebook-mcp-cli (https://github.com/jacob-bd/gemini-notebook-mcp-cli): install with uv tool install notebooklm-mcp-cli (or pipx install notebooklm-mcp-cli if uv isn't installed), run nlm login (I sign in to Google; give it up to 5 minutes, and just re-run it if your command times out), then nlm setup add claude-code (or nlm setup add claude-desktop; the bare nlm setup wizard only works in a terminal I type in), then restart the app so the new server loads. Avoid the older PleasePrompto notebooklm-mcp npm package; it is archived and no longer maintained. Do the available setup work, and pause for me only when I need to sign in, enter a secret, approve access or confirm a purchase. Check current plan requirements before a paid step. Keep passwords and API keys out of the chat. If browser tools are unavailable, give me the exact next link and action. Apify's free plan gives $5 of credit a month and the Instagram scraper costs about $2.70 per 1,000 results on it, so tell me roughly what my rival list will cost per run before the first scrape. If a signup form asks how I heard about it, use M Kazigwa. Verify the required connections with a small test. Tell me what is ready and anything still missing. Then identify the first execution prompt to use. Do not run the build prompts until setup is ready.

    02

    Build

    Copy block 1 · page 2

    You have access to [Composio / Unipile / the Instagram Graph API].

Connect my Instagram business account and pull my last 90 days of posts.

For each post return: date, format (reel / carousel / static), the hook

(first line), caption, and metrics — reach, views, avg watch time (reels only),

likes, comments, saves, shares, and follows-from-post.

If you're using Composio, list my posts with INSTAGRAM_GET_IG_USER_MEDIA

(ig_user_id = me; not the deprecated INSTAGRAM_GET_USER_MEDIA), then get

each post's numbers with INSTAGRAM_GET_IG_MEDIA_INSIGHTS. Ask it for reach,

views, saved, shares, likes, comments and follows, plus ig_reels_avg_watch_time

for reels (plays is retired; views replaced it). If insights come back empty,

or a metric is missing or rejected for a post type (Composio says insights

need 1,000+ followers), drop that metric, tell me, and fill what the media

list gives.

Output one clean CSV called my_content.csv, sorted by reach descending.
    03

    Build

    Copy block 2 · page 4

    Using Composio, connect my Instagram business account.

Then pull my last 90 days of media with INSTAGRAM_GET_IG_USER_MEDIA

(ig_user_id = me, since = the Unix time 90 days ago, and page through

with the after cursor; the old INSTAGRAM_GET_USER_MEDIA is deprecated). For each post, get its

insights with INSTAGRAM_GET_IG_MEDIA_INSIGHTS — reach, saved, shares, views, likes, comments.

Output my_content.csv sorted by reach descending.

    Build

    Copy block 3 · page 5

    Using Unipile (account_id acc_xxxxx), pull my recent Instagram

and LinkedIn posts with caption, format, date, and engagement

(likes, comments, views). Output my_content.csv.

    Build

GET /{user-id}/media                 -> list your posts

   reach,saved,shares,total_interactions,views,likes,comments

# do this for each media id, then compile my_content.csv
    06

    Build

    Copy block 5 · page 8

    Using [Apify’s Instagram scraper / Firecrawl], scrape these 15 creators:

[@handle1, @handle2, …].

For each, pull their last 30 posts with: hook (first line), caption,

format, view count, likes, comments, and post date.

Rank every post by views, keep the top 20% per creator.

Output competitors.csv.

Cost check before you run it on Apify: 15 creators × 30 posts is about

450 results, roughly $1.20 a run on the free plan ($2.70 per 1,000

results, $5 of free credit a month). Tell me the estimate and my

remaining credit first.
    07

    Build

    Copy block 6 · page 9

    Here are two datasets: my_content.csv (my posts + metrics) and

competitors.csv (top creators’ posts + metrics). Analyse them together

and produce a FINDINGS BRIEF, not a data dump:

  1. my top 5 hooks/formats by saves & follows — what they share

  2. my bottom 5 — the pattern that’s killing them

  3. hooks/structures in rivals’ outliers that I am NOT doing

  4. 5 specific, testable changes for my next posts, each tied to evidence

Max 1.5 pages. Output findings.md.
    08

    Build

    Copy block 7 · page 10

    Using the Gemini Notebook MCP (gemini-notebook-mcp-cli; Gemini Notebook is

what NotebookLM is called since July 2026): create a notebook called

‘Content Coach — [month]’. Add findings.md as a source.

Wait until it’s ready, then confirm the source is in.

Also add last month’s findings so the notebook compounds over time.
    09

    Build

    Copy block 8 · page 11

    In the Content Coach notebook in Gemini Notebook, generate:

  1. an Audio Overview (Deep Dive) steered to: ‘what’s working in my

     content, what my rivals do that I don’t, and the 5 changes to make next’

  2. a Study Guide

  3. a Briefing Doc

  4. Flashcards on my winning hooks

Then download the audio.
    10

    Build

    Copy block 9 · page 12

    Every 3 days, re-run OP1–OP5 automatically:

  • pull my newest posts   • re-scrape my rival list

  • regenerate findings.md  • refresh the Gemini Notebook notebook

  • generate a fresh Audio Overview

Then message me when the new deep-dive is ready to listen to.

Cost note: re-scraping 15 rivals every 3 days is about 10 runs and

4,500 Apify results a month, roughly $12, which is more than Apify's $5

free credit. Unless I've told you I'm on a paid Apify plan, re-scrape

the rivals once a week instead (about $5.25 a month, a little over the free credit) and keep pulling my

own posts every 3 days. Check my Apify balance before each scrape and

skip it, telling me, if the run would go over.
